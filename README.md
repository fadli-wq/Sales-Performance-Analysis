# SalesPerformance Analysis (Power BI Dashboard)

## Project Overview
Proyek ini bertujuan untuk membangun sebuah *dashboard* analitik bisnis interaktif menggunakan **Power BI** guna menganalisis performa penjualan (*sales*), tren bulanan, total pesanan (*total orders*), serta distribusi pendapatan berdasarkan wilayah (*regional performance*). Proyek ini dirancang untuk menyajikan *insight* bisnis yang komprehensif dan mendukung proses pengambilan keputusan strategis berbasis data.

---

## Tools & Technologies
* **Power BI Desktop:** Pembuatan model data, pengukuran metrik (*measures*), dan perancangan *dashboard* interaktif.
* **Power Query:** Pembersihan data awal (*data cleaning*), validasi tipe data, dan transformasi struktur tabel.

---

## Dataset Structure
Proyek ini menggunakan struktur data relasional yang terdiri dari 3 tabel utama:
1. **Customers:** Berisi informasi demografi dan wilayah pelanggan.
2. **Orders:** Berisi catatan transaksi penjualan harian.
3. **Products:** Berisi informasi produk dan kategori.

---

## Key Dashboard Metrics & Insights
* **Total Sales:** Mencapai **42K** secara keseluruhan dari berbagai wilayah operasional.
* **Average Sales:** Rata-rata transaksi penjualan berada di kisaran **2.09K**.
* **Total Orders:** Sebanyak **20 total pesanan** berhasil dicatat dan diproses selama periode waktu analisis.
* **Regional Performance:** Wilayah **East** mendominasi kontribusi penjualan tertinggi dibandingkan wilayah lainnya (North, South, dan West).
* **Sales Trend:** Menunjukkan fluktuasi bulanan dengan puncak transaksi tertinggi terjadi pada bulan Maret.
